General settings

Choose how members use Fate and where commands are allowed.

Command prefix

The characters members type before a command. Use one to five characters with no spaces.

Personal prefixes

Allow members to choose a prefix that follows them across Fate servers.

Bot language

Choose the language Fate uses for messages and command responses in this server.

Bulk delete limit

The most messages a moderator can remove with one command.

messages

Confirm purge commands

Ask moderators to confirm before Fate deletes messages. On by default; moderators can choose “Don’t ask again” at the prompt.

Warning channel

Command-free channels
