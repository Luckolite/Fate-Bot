# Autonomic evaluation fixtures

`cases.json` contains hand-authored, fictional numeric contexts for testing the
deterministic autonomic composition code. It contains no messages, names,
accounts, actor identifiers, personal histories, diagnoses, or observations of
real people.

The cases test software expectations only:

- social engagement as the safe baseline attractor;
- rapid bounded mobilization under explicit threat or boundary pressure;
- persistence after one safe frame when activation remains high;
- gradual reduction in activation, load, and mobilization across repeated
  safety, agency, connection, and repair contexts;
- conservation under sustained load and low controllability;
- strategy ordering, output bounds, and hysteresis near mode boundaries.

They are not clinical labels, neuroscience evidence, population norms, or a
training dataset. Any future evaluation data derived from real interactions
requires a separate consent, privacy, governance, bias, and retention review;
it must not be silently mixed into this fixture set.
